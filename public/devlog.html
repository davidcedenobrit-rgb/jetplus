Impacto

Antes vs. Después

✗ Antes de Navi Dev
✗ Control de créditos en hojas Excel sin historial ni trazabilidad
✗ Ingresos registrados manualmente, sin validaciones ni estados
✗ Sin control de quién aprobó qué ni cuándo
✗ Carla recibía depósitos sin registro formal ni confirmación digital
✗ No había forma de saber el saldo real de cada crédito en tiempo real
✗ Acceso desde escritorio únicamente, sin versión móvil
✗ Sin separación de roles — todos veían y podían hacer todo
✗ Reportes manuales que José pedía cada vez a su equipo
✗ Inventario de vehículos gestionado aparte, sin conexión a ventas
✗ Sin dominio propio ni app instalable en el teléfono
✓ Con el Centro de Mando
✓ Créditos con cuotas, saldos automáticos y pagos asociados a recibos
✓ Ingresos con 8 estados, timestamps y flujo de aprobación completo
✓ Log de auditoría con fecha, usuario y acción en cada operación
✓ Módulo Carla: tabla de entregas pendientes y entregadas con fecha
✓ Saldo actualizado automáticamente al registrar cada pago
✓ Diseño mobile-first, sidebar drawer, PWA instalable en iPhone y Android
✓ 5 roles con permisos granulares: jose, admin, director, carla, editor
✓ Dashboard con KPIs en tiempo real, reportes por módulo
✓ Inventario vinculado a clientes, créditos e ingresos
✓ Dominio propio centrodemando.laoriental.co + ícono de marca

✓

Búsqueda y listado paginado

Módulo de Vehículos
✓
Inventario de vehículos MG & MAXUS
Registro de placa, modelo, año, color, VIN, precio base en USD

Calculadora de financiamiento automática

Módulo de Ingresos — Flujo de 8 estados
✓
Registro de recibo de ingreso
Número de recibo, monto, moneda (USD/VES), método de pago, concepto, placa
✓
Flujo de 8 estados con timestamps por paso

✓
Timeline de auditoría en cada recibo
Línea de tiempo visual con icono, estado y fecha de cada transición
✓
Botones de acción condicionales por rol y estado
Cada botón aparece solo si el estado actual lo permite y el rol del usuario está autorizado
✓
Acción "Entregado a Carla" restringida a directores

✓
Confirmación de depósito (Confirmar depósito)
Paso explícito de enviado_deposito → depositado con timestamp deposito_at
✓
Listado con filtros por estado y búsqueda

Badges de color por estado en la lista

         │
         ▼
  Next.js 15 App Router  ──  Edge Middleware  ──  Auth Guard
         │
    ┌────┴────┐
    │         │
Server Components   Client Components
(SSR, data fetch)    (interactividad, forms)
    │
    ▼
Supabase PostgreSQL  ──  Row-Level Security (RLS)
    │
    ├── clientes
    ├── vehiculos
    ├── ingresos       ←── estado machine (8 estados)
    ├── egresos
    ├── creditos
    ├── cuotas
    ├── cuota_ingresos  ←── junction table (pagos parciales)
    ├── tasas
    └── solicitudes_cambio

ImageResponse  ──  Íconos dinámicos    ──  PWA + iOS
