Impacto

Antes vs. Después

✗ Antes de Navi Dev
✗Control de créditos en hojas Excel sin historial ni trazabilidad
✗Ingresos registrados manualmente, sin validaciones ni estados
✗Sin control de quién aprobó qué ni cuándo
✗Carla recibía depósitos sin registro formal ni confirmación digital
✗Sin forma de saber el saldo real de cada crédito en tiempo real
✗Acceso solo desde escritorio, sin versión móvil
✗Sin separación de roles — todos veían y podían hacer todo
✗Reportes manuales que José pedía a su equipo cada vez
✗Inventario de vehículos gestionado aparte, desconectado
✗Sin dominio propio ni app instalable en el teléfono
✓ Con el Centro de Mando
✓Créditos con cuotas, saldos automáticos y pagos vinculados a recibos
✓Ingresos con 8 estados, timestamps y flujo de aprobación completo
✓Log de auditoría con fecha, usuario y acción en cada operación
✓Módulo Carla: tabla de entregas pendientes y entregadas con fecha
✓Saldo actualizado automáticamente al registrar cada pago
✓Diseño mobile-first, sidebar drawer, PWA instalable en iOS y Android
✓5 roles con permisos granulares: jose, admin, director, carla, editor
✓Dashboard con KPIs en tiempo real, reportes por módulo
✓Inventario vinculado a clientes, créditos e ingresos
✓Dominio propio centrodemando.laoriental.co + ícono de marca

Autenticación & Roles

✓
5 roles con permisos granulares
jose · admin · director · carla · editor — acceso diferenciado por módulo y acción
✓
Protección de rutas por rol
Redirect automático si el usuario no tiene el rol requerido para la página
✓
Badges de rol en el sidebar
Indicadores visuales DIR y CARLA según el usuario autenticado
Módulo de Clientes
✓
Registro y edición de clientes
Nombre, cédula/RIF, teléfono, dirección y datos de contacto
✓
Ficha de cliente consolidada
Vista de créditos, ingresos y vehículos asociados desde un solo punto
✓
Búsqueda y listado paginado
Filtrado por nombre o cédula/RIF en tiempo real
Módulo de Vehículos
✓
Inventario de vehículos MG & MAXUS
Placa, modelo, año, color, VIN, precio base en USD
✓
Calculadora de financiamiento automática
Precio base + 16% IVA + gastos admin = precio total con Saldo a Financiar en tiempo real
✓
Corrección anti-NaN en campos de moneda
Validación defensiva en formatUSD que evita el bug "USDNaN" al dejar campos vacíos
✓
Vinculación vehículo → cliente → crédito
Relación directa entre el vehículo financiado y su expediente financiero
Módulo de Ingresos — Flujo de 8 estados
✓
Registro de recibo de ingreso
Número de recibo, monto, moneda (USD/VES), método de pago, concepto, placa
✓
State machine de 8 estados con timestamps
registrado → pendiente_aprobacion → aprobado → enviado_carla → enviado_deposito → depositado → entregado_carla → reportado_vehimotors
✓
Timeline de auditoría por recibo
Línea de tiempo visual con ícono, estado y fecha de cada transición
✓
Botones de acción condicionales por rol y estado
Cada acción aparece solo si el estado actual lo permite y el rol del usuario está autorizado
✓
Acción "Entregado a Carla" restringida a directores
Solo roles jose/admin/director pueden marcar el depósito como entregado; guarda entregado_carla_at
✓
Confirmación de depósito explícita
Paso enviado_deposito → depositado con timestamp deposito_at registrado
✓
Filtros por estado con chips clicables
8 filtros incluyendo "Entregado Carla", con badges de color diferenciado por estado
Módulo Carla — Control de Depósitos
✓
Dashboard exclusivo para Carla
Vista dedicada con pendientes y ya entregados, accesible solo por roles autorizados
✓
Tabla de pendientes con monto total
Ingresos en estado "depositado" ordenados por fecha de depósito más antigua
✓
Tabla de entregados con fecha de entrega
Historial de los últimos 50 ingresos marcados como entregado_carla con timestamp
✓
Badge de pendientes en sidebar
Contador en tiempo real visible para roles autorizados, desaparece al estar al día
✓
Migración DB: columna entregado_carla_at
